### 🔥 Current Project: DeckERP

*A packaged, cloud-native SaaS ERP built from the ground up.*

🔗 **Live Demo → [deck-erp.vercel.app](https://deck-erp.vercel.app)**

| Feature | Technology / Architecture |
| :--- | :--- |
| **Backend** | .NET 8 (ASP.NET Core Web API) |
| **Frontend** | React 18 |
| **Architecture** | Clean Architecture, CQRS, DDD |
| **Database** | PostgreSQL (EF Core Code-First) |
| **Containerization** | Docker & Docker Compose |
| **Hosting** | Railway (API) + Vercel (Frontend) |
| **API Docs** | Swagger / OpenAPI |
| **Validation** | FluentValidation |
| **Mapping** | AutoMapper |

**Key features:** Multi-currency orders (TRY/USD/EUR) with live TCMB exchange rates, Ana Ürün–Variation (Parent-Child) SKU architecture, BOM management, role-based access control, configurable settings for each company.

### 💼 Experience

**Software Developer Intern — Ditetra Innovation & Renled Lighting** *(Sep 2025 – May 2026)*

As the company's **sole developer**, I rebuilt the existing system from the ground up into a fully functional ERP actively used in production:

* Migrated a monolithic PHP codebase to Clean Architecture (`App\Modules\{Module}\{Layer}`), splitting 3,000+ line files into focused components under 200 lines each
* Eliminated 400+ independent SELECT queries with JOIN optimization, achieving **~90% performance improvement**
* Implemented full security layer: CSRF protection, 2FA with Google Authenticator (TOTP), CAPTCHA, and 12-character minimum password policy
* Built an invoice module with live TCMB exchange rate integration and multi-currency support (TRY/USD/EUR)
* Designed order lifecycle (draft → procurement → production → delivery → invoice) with RBAC across 5 roles: Admin, Sales, Production, Shipping, Accounting
