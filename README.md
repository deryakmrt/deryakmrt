### 👩‍💻 About Me
Hello! I am a **Computer Engineering** student at **Necmettin Erbakan University**.

I started my software journey developing monolithic systems with PHP. However, realizing the importance of sustainability, performance, and scalability at an enterprise level, I shifted my focus to **Modern Software Architectures**.

Currently, I am building a global-standard ERP system from scratch by combining the ERP business logic I gained from my internship experiences with **.NET 8, Docker, and Kubernetes** technologies. I am documenting and coding my transition from spaghetti code to **Clean Architecture**.

### 🔥 Current Project: Modern ERP System
*A modern solution to the "Technical Debt" issues of legacy monolithic structures.*

I am re-engineering a corporate ERP system (Inventory, Sales, CRM, Finance) from the ground up using the latest technologies and **Clean Architecture** principles.

| Feature | Technology / Architecture |
| :--- | :--- |
| **Backend** | .NET 8 (ASP.NET Core Web API) |
| **Architecture** | Clean Architecture, CQRS, DDD |
| **Database** | PostgreSQL (EF Core Code-First) |
| **Containerization** | Docker & Docker Compose |
| **API Docs** | Swagger / OpenAPI |
| **Validation** | FluentValidation |
| **Mapping** | AutoMapper |

🔗 **Goal:** Evolve this project into a Microservices architecture and deploy it on Kubernetes.
